# Epic Names

Family and character charts from three Sanskrit works. Choose a chart to see its sources and naming notes.

- [Ramayana](ramayana.md)
- [Mahabharata](mahabharata.md)
- [Srimad Bhagavatam](bhagavatam.md)

[Open the interactive viewer](https://skkc2.github.io/Epic-Names/). Its source files are in [docs](docs/). The [GitHub Actions workflow](.github/workflows/pages.yml) publishes `/docs` to GitHub Pages when the viewer changes on `main`. In **Settings → Pages**, set **Source** to **GitHub Actions**.
