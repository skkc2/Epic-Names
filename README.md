# Epic Names

Family and character charts from three Sanskrit works. Choose a chart to see its sources and naming notes.

- [Ramayana](ramayana.md)
- [Mahabharata](mahabharata.md)
- [Srimad Bhagavatam](bhagavatam.md)

The interactive viewer lives in [docs](docs/). The [GitHub Actions workflow](.github/workflows/pages.yml) publishes `/docs` to GitHub Pages when the viewer changes on `main`. In **Settings → Pages**, set **Source** to **GitHub Actions**.
